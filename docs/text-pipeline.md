# Text stages and glossary

The deterministic stages between the recognizer and delivery, and the vocabulary that drives them. [AGENTS.md](../AGENTS.md) maps the other contracts; [`.omp/RULES.md`](../.omp/RULES.md) holds the invariants every change keeps.

## Text pipeline

Order (`DictationTextStage.apply`, shared by the app and `voiceour-bench pipeline`/`granite-spot`): term spotting, then `LiteralComposition.apply`, then `CleanupEngine.clean` + `VocabularyRepairEngine.repair`; spotting, cleanup and repair only when `Settings.cleanupEnabled`. Pure functions of transcript + recognizer term spots + utterance vocabulary snapshot. Empty output → `cancelled`. History keeps raw ASR (the greedy transcript, never the spotted one) and final text; least-confident word comes from raw words.

- Term spotting: `TermSpotTargets` (VoiceCore) is the one builder of targets, protected surfaces and variants, used by the app and the bench. Targets = snapshot canonicals passing `TermSpotting.isTarget` (not ordinary English, >2 characters); every other canonical is a protected surface. Variants = `TermSpotting.variants(for:)`: canonical, case forms, `Glossary.derivedAliases`; NEVER a heard-as/spoken/labeled alias (wave 2's taught arm: 1,472 false activations). Applies only on `DictationLanguage.usesEnglishRules(detect(raw))` and when the transcript's words joined by single spaces equal its text; the later stages (`DictationTextStage.stages`) then run on the spotted text under the raw transcript's language, never re-detected. `TermSpottingPolicy.frozen = (6, 1.5, 1)`, frozen by the preregistered [wave 2](../research/granite-ctc-word-spotting-wave2-2026-11-06.md); changing it requires a new preregistered wave.

- Language: `DictationLanguage.detect(raw)` once per utterance — kana or ≥30% Han → `ja`; otherwise weighted function words with apostrophe-aware tokens, winner ≥1.5 with a 0.5 lead, else nil. Deterministic, Foundation-only; NEVER NaturalLanguage or a model. English rules (literal commands, filler removal, repeat collapse, sentence-case repair, phonetic repair, `CandidateRetrieval`) apply only when `DictationLanguage.usesEnglishRules` (en or nil). Other languages get whitespace normalization + `Glossary.canonicalize(language:)`, where a one-word letters-only canonical with at most an initial capital (`Glossary.isSpelledAsAWord`) never matches its own surface. Changing word lists, thresholds or gated stages requires English misrouting and per-language accuracy evidence on transcripts the change was not tuned on ([measurements](benchmarks.md#multilingual-text-stage--2026-11-06)).

- Literal commands: `spell`, `spell that`, `letter by letter` / `letter-by-letter`, `literal`, `snake case`, `camel case`, `capital` / `uppercase`, `dash`, `dash dash`, `dot`, `underscore`. Whole-word, case-insensitive matching; runs cross single spaces and end at punctuation. No match → unchanged input. Standalone symbol words apply anywhere, including prose.
- Cleanup: normalize whitespace; remove fixed `um`, `uh`, `uhm`, `erm`, `mmm`, `hmm`; collapse immediate repeats up to four words; repair sentence case only when deletion exposes an all-lower-case token and the original sentence was capitalized; then `Glossary.canonicalize`.
- Protected from filler removal/recasing: glossary surfaces; tokens starting with `-` or containing `/`, `~`, `_`, digits, or internal capitals. MUST shelter multi-word glossary surfaces by applying the deletion passes to detect damage, not by duplicating their rules.
- Canonicalization MUST gather canonical/user/derived alias matches against original text, resolve longest-first then leftmost, apply right-to-left. Escape replacements with `NSRegularExpression.escapedTemplate`. `Glossary.derivedAliases`: `SwiftUI` → `swift ui`, `swift u i`; single-letter aliases and all-digit canonicals never generalize. A one-word ordinary-English or ≤2-character canonical never matches its own surface (`Glossary.recasesOwnSurface`), only its user/derived aliases: case normalization would rewrite ordinary prose. Retrieval (`CandidateRetrieval`) still sees those surfaces.
- Repair: exact aliases first/longest; highest-scoring phonetic candidates then occupy unclaimed spans of up to five words. `RepairVocabulary.frozenPhoneticThreshold = 0.95`; lowering it requires safety evidence, not a better score.
- Ordinary-English and ≤2-character canonicals MUST NOT be repair targets; protect their occurrences. Reject multi-word phonetic candidates composed entirely of ordinary words. Only `a` and `i` count as ordinary single letters.
- Cache the repair engine by ordered active canonicals; rebuild only when those change. `voiceour-bench pipeline` repairs only with `--vocabulary`; the sidecar never repairs its own transcript.
- `VocabularyCompiler.compile`: ≤100 terms; explicit corrections/protected terms (including bundled defaults) first; then trust, recency, index order with source quotas/backfill. Terms apply globally, never by app/project.
- Ordinary-word resource: `Sources/VoiceCore/Resources/ordinary-words.txt`, generated by `scripts/generate_ordinary_words.py` from frozen research vocabulary. `RepairVocabulary.bundledOrdinaryWords` uses packaged `voiceour_VoiceCore.bundle` or `Bundle.module`. Missing/unreadable list → precondition failure; bundling requires the resource bundle; bundle verification requires a non-empty list.
- `CandidateRetrieval` uses the utterance's vocabulary snapshot after delivery, on a detached utility task over final text, English or undetermined transcripts only; accept results only for the current generation; clear at next recording. Suggestions never edit delivered text or the target. Secure-target retrieval currently also runs; persistence still requires explicit acceptance.

## Spoken note command

`NotePrefix.strip(from:language:)` (`Sources/VoiceCore/NoteCapture.swift`) decides whether a dictation is a note. It is NOT a text stage and NEVER changes delivered text: the app's note branch calls it on the final text, after `DictationTextStage.apply` and the empty-transcript check, and only for a `.deliver` session whose delivery target is not secure ([runtime.md › Runtime flow](runtime.md#runtime-flow)). Nil → the dictation is delivered exactly as the stages produced it; a string → that string is saved as a note and nothing is delivered. `voiceour-bench` never runs it.

- Grammar: optional leading whitespace, then the words `note`, `to`, `self` at the very start, each a whole word of letters and digits compared without case, separated by whitespace. The next character MUST be whitespace, one of `,` `.` `:` `;` `-` `–` `—`, or the end of the text; anything else (`note to self's list`) → nil. The words anywhere but the start → nil.
- Gating: only when `DictationLanguage.usesEnglishRules(language)` holds for the language `DictationTextStage.apply` reported (English or undetermined); any other language → nil.
- Output: the text with the command and the run of whitespace and those punctuation marks after it removed. An empty remainder → nil, so a bare “note to self” is delivered. A lower-case first letter is upper-cased, because the command took the sentence's start; every other character stays as the stages left it.
- A `.note` session (the menu's Take a Note, the Notes lens) saves its final text whole; the command is not read for it.

## Glossary rules

- MUST reject generalizable aliases colliding case-insensitively with another canonical or alias. Enforce in Teach, Glossary add/save, suggestion acceptance, import. Reject the whole ambiguous proposal; validate the merged import before assignment.
- Import shapes: JSON spelling array, rows such as `[{"term":"kubectl","heard_as":["Qbectal"]}]`, or newline spellings. MUST filter unsafe/oversized surfaces with `VocabularySanitizer.isSafe`, not clean them; deduplicate case-insensitively against canonical and aliases. One invalid form MUST NOT discard valid forms in its row.
- `WordListLimits`: 500 terms, 64 characters/term, 8 aliases/term. Imported terms: unprotected `manualImport`.
- Confirm/reject/import/remove/clear vocabulary only on explicit user action. Background learning is forbidden.
- Both editors expose Term + Heard as inputs and read-only *Also matched* derived forms.
- History ⌘T on an owned surface MUST open its existing term, canonical and full user-alias set; save using that term id/full-set semantics. Unowned surface → blank canonical, additive save.
- Teach shows an empty additional-form field only when its form set is empty. Glossary editors always show it.
